How to play

Your prompt. Your game. Everyone can publish.

  1. 01
    Clone the repository

    Pick an idea, clone the repo, and create a new folder at games/<slug>/.

  2. 02
    Build it with one prompt

    Use a single prompt to generate a self-contained static game in index.html. Add a valid prompt.json with the game metadata, model, author, and exact prompt you used.

  3. 03
    Open a merge request

    Submit your game for review. Once it checks out, it will be merged and published in the arcade—so anyone can share a funny game with everyone.
